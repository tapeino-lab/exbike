# EX-BIKE

縦持ちスマホで遊ぶ、モトクロスのタイムアタックゲーム。

▶ https://tapeino-lab.github.io/exbike/

## あそびかた

| そうさ | 両手 | 片手 |
|---|---|---|
| 加速 | A | A を押しっぱなし |
| ターボ | B | 指を B へずらす |
| レーン移動 | 十字キー ↑↓ | 押したまま上下にスライド |
| 空中で傾ける | 十字キー ↑↓（←→） | 押したまま上下にスライド |

- ターボを使いすぎるとエンジンがオーバーヒートして止まる。青い矢印の上を通ると冷える。
- ジャンプの着地は、車体の角度を地面に合わせるとうまくいく。
- タイトル画面で SELECT を押すと、左手用の配置になる。
